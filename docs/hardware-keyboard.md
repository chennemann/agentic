# Hardware keyboard shortcuts

Agentic uses the same guarded UI actions for hardware shortcuts and touch controls.

| Shortcut | Action |
| --- | --- |
| `Ctrl/⌘ + Enter` | Send the non-empty enabled composer draft |
| `Shift + Enter` | Insert a newline |
| `Esc` | Stop the current turn when one is running and the composer has focus |
| `Ctrl/⌘ + N` | Start a new task through the normal project/thread selection flow |
| `Ctrl/⌘ + K` | Open navigation and search choices |

Key-up events, held-key repeats, unsupported modifier combinations, and unavailable actions are ignored. Shortcuts never bypass confirmation dialogs or server-derived availability checks.
