# T3–Agentic capability-parity inventory

## Scope and reading guide

This inventory reconciles the frozen T3 desktop/web and React Native mobile clients at
[`0ad91b6`](https://github.com/chennemann/t3code/tree/0ad91b6e7fc1fcb6d5f4bc736d84c337e912bc62),
portable protocol v1/server shim at
[`0ed0543`](https://github.com/chennemann/t3code/tree/0ed054375c12940436df680807a05fd4aa3be5f6),
and Agentic at
[`4e2bdc7`](https://github.com/chennemann/agentic/tree/4e2bdc73005cc6c51ea29df2870dddecf9dc18fd).
It is a static-source inventory, not an implementation plan. Reference-client presentation is
evidence that a behavior exists, never an Android UI requirement.

Evidence statuses are **present**, **partial**, **absent**, and **unverified**. Maturity is
**stable**, **experimental**, **pre-release**, **optional**, or **capability-gated**; combined
values mean availability varies by reference client. Priorities express dependency and workflow
value, not delivery order: **P0** is required for the core remote agent loop, **P1** unlocks a
major daily workflow or recovery guarantee, **P2** adds valuable adjacent workflow coverage, and
**P3** is specialized or host-specific. “N/A” in portable evidence means client-local behavior,
not a protocol defect.

## Disposition summary

The frozen evidence establishes the central portable conversation loop, provider neutrality,
thread browsing/basic lifecycle, projection caching and sequence recovery as parity achieved.
The highest-value Android-only gaps are environment removal, durable command outbox, thread delete,
and completing already-portable plan/checkpoint/session actions. The largest cross-boundary gaps are
projects/worktrees, files and complete diffs, source-control/review/terminal workflows, and
background notification awareness. Host administration, Electron preview automation, iOS-only
activities, and experimental auto-settlement are intentionally outside this Android-client parity
destination.

No row prescribes a server design, Android presentation, estimate, schedule, or implementation
ticket. Rows marked **unverified** require behavioral evidence before their ownership can be narrowed
further.
